# 🧱 Bloco de Tarefas (Kanban Board)

Um simples e interativo **bloco de tarefas** estilo *Kanban*, desenvolvido com **HTML, CSS e JavaScript puro**.  
Permite criar, editar, arrastar e organizar tarefas entre colunas — tudo direto no navegador.

---

## 🚀 Funcionalidades

- ✏️ Criar novas tarefas com **duplo clique** em uma coluna.  
- 🖱️ **Arrastar e soltar** tarefas entre colunas.  
- 🧠 **Editar** qualquer tarefa com duplo clique.  
- 🧹 **Remover automaticamente** tarefas vazias.  
- 🎨 Destaque visual ao arrastar tarefas.  
- 🔒 Interface simples, sem necessidade de login.

---

## 🧰 Tecnologias Utilizadas

- **HTML5** → estrutura das colunas e cards  
- **CSS3** → estilo e layout responsivo  
- **JavaScript (ES6)** → lógica de drag-and-drop e criação dinâmica de cards
